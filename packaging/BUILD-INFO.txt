AUTO-UPDATE DEL PROYECTO NPM
----------------------------
• En clones, “npm start” ejecuta git fetch sobre la rama actual y solo permite
  avance rápido; nunca fuerza, resetea ni sobrescribe cambios locales.
• En copias ZIP consulta la revisión por la API de GitHub y sincroniza un ZIP de
  fuentes administradas sin tocar VozLarga-PC-1.0 ni node_modules.
• Tras una actualización sincroniza npm sin postinstall recursivo y ejecuta
  setup incremental.
• Los modelos con tamaño y SHA-256 válidos se reutilizan. Checkpoints, audios y
  transcripciones se conservan.
• Sin red o con una rama Git divergente, inicia la versión local.
• “npm run start:offline” omite completamente la comprobación de red.

PIPELINE DE LA INTERFAZ
-----------------------
• Sondeo local de duración con FFmpeg.
• Bloques de hasta 900 s, paso de 898 s (2 s de solapamiento).
• PCM WAV a 16 kHz mono, o estéreo cuando se solicita diarización por canales.
• Mejora opcional y determinista: highpass 70 Hz, lowpass 7600 Hz, afftdn y
  dynaudnorm. Si falla, reintento automático sin filtros.
• Analizador PCM interno de RMS, pico, clipping, formato y silencio; bloques
  silenciosos se omiten sin llamar a Whisper.
• Idioma fijado a español; solo se usa el vocabulario escrito por el usuario.
  No se realimenta la hipótesis anterior porque puede propagar una frase falsa.
• Decodificación conservadora: temperatura 0, sin fallback de temperatura,
  beam search 8, supresión no verbal y umbral no-speech 0,55.
• Diarización estéreo opcional de whisper.cpp; no separa voces del mismo canal.
• Silero VAD opcional, activado por defecto para Vulkan; el respaldo CPU lo
  omite para evitar la regresión de rendimiento medida en audio largo.
• Vulkan primero, watchdog de 20 minutos por bloque y reintento CPU sin VAD
  del mismo bloque ante error o timeout.
• Checkpoint atómico después de verificar cada TXT de bloque.
• Eliminación de texto repetido en el solapamiento mediante coincidencia de
  sufijo/prefijo de palabras.
• Consolidación UTF-8, párrafos deterministas, escritura temporal duradera,
  lectura de verificación, reemplazo final atómico y borrado de temporales.
• Botones para abrir el TXT en el editor de Windows y reproducir el audio.

VERIFICACIÓN REALIZADA EN EL ENTORNO DE CONSTRUCCIÓN
-----------------------------------------------------
• Compilación Release completa de ambos motores y de la GUI: correcta.
• Inspección PE/COFF x64 y dependencias importadas: correcta.
• whisper-vulkan.exe importa vulkan-1.dll; whisper-cpu.exe no la importa.
• Los motores y la GUI no requieren libc++, libunwind ni DLL de ggml.
• Silero VAD: tamaño y SHA-256 verificados localmente. Large v3 Turbo Q5_0:
  setup exige tamaño y SHA-256 oficiales antes de aceptar la descarga.
• Regresión con MP3 y M4A sintéticos de 2 horas: 9 bloques por archivo, 18 WAV
  validados. Pipeline completo MP3 de 2 horas: 9/9 bloques y TXT final válidos.
  Consulte TEST-RESULTS.txt.
• Estructura portable y manifiesto: verificados.
• Integridad del ZIP mediante listado, prueba CRC y SHA-256: se verifica al
  generar la entrega.

NO REALIZADO AQUÍ
-----------------
Este entorno Linux no dispone de Windows, controlador AMD ni una RX 5600 XT.
Por tanto no se ejecutó un benchmark real, no se validó el diálogo gráfico en
Windows físico y no se garantiza el objetivo de velocidad. La primera prueba
debe hacerse según BENCHMARK.txt. El respaldo CPU está incluido para cubrir un
fallo de inicialización o ejecución Vulkan.
